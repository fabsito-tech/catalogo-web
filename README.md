# Catálogo web — Esquina

Catálogo responsive de muestra, hecho con HTML, CSS y JavaScript sin dependencias externas.

## Qué incluye

- Búsqueda por nombre, categoría o etiqueta.
- Filtros por categoría y orden por precio.
- Carrito con cantidades, subtotal y persistencia local en el navegador.
- Diseño adaptable a móvil y escritorio.
- Productos y precios de ejemplo en pesos argentinos.

## Probarlo

Abrí `index.html` en un navegador. No requiere instalación ni servidor.

## Personalizar productos

Editá la lista `products` al inicio de `app.js`. Cada producto tiene `id`, `name`, `category`, `price`, `emoji`, `tag`, `bg` y `rating`; `oldPrice` es opcional.

## Importante

Es una demo frontend: el carrito queda guardado solo en el navegador de cada persona. No hay login, stock compartido, pagos ni envío real de pedidos. El repositorio se creó privado; para publicar la web y compartirla habrá que cambiar su visibilidad y configurar GitHub Pages.
